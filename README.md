# DATABASE-MYSQL-GROUP-ASSIGNMENT-PLP
This repository contains the SQL scripts for building a MySQL database to manage a bookstore. It includes the database schema design, SQL commands for creating tables, instructions for loading sample data, and examples of setting up user roles and privileges. It comes along with draw.io diagrams visualizing the database schema and relationships

Key Features:**
* **Database Schema Design:** A well-structured schema covering books, authors, customers, orders, shipping, and related entities, visualized with draw.io diagrams. 
* **SQL Table Creation:** Comprehensive `CREATE TABLE` statements with appropriate data types, primary keys, foreign keys, and constraints to ensure data integrity.
* **Sample Data Loading:** `INSERT` statements to populate the tables with realistic sample data for testing and demonstration.
* **User Management:** Examples of creating MySQL users with different roles and granting specific privileges for security (e.g., admin, read-only, order manager).
* **Illustrative Test Queries:** Basic `SELECT` queries demonstrating data retrieval and relationships between tables.
* **ERD Visualization:** Includes draw.io diagrams (`*.drawio` or exported image) clearly illustrating the database schema and the relationships between the tables.

**Purpose:**
This project serves as a hands-on exercise in designing and implementing a relational database for a practical use case. It aims to demonstrate an understanding of SQL concepts, database normalization principles, basic database administration tasks, and the ability to visualize database structures using ER diagrams.

**Tools and Technologies:**
* MySQL
* draw.io

**Getting Started:**
1.  Clone this repository.
2.  Connect to your MySQL server.
3.  Execute the SQL script (`*.sql` file) to create the database and tables.
4.  (Optional: Execute the data loading script to populate the database).
5.  View the draw.io diagrams (`*.drawio` file or exported image) to understand the database structure.
